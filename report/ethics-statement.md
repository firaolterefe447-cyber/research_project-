# Ethics Statement

## Participation

Participation in questionnaires, interviews, and observations is voluntary. Participants may decline or stop participation without penalty. Written or verbal consent must be obtained according to institutional requirements.

## Minimization and Confidentiality

The study will collect only information necessary to answer the research questions. Public repository files will not contain names, student IDs, email addresses, phone numbers, exact locations, or identifiable quotations.

## Data Protection

- Raw records must be stored securely and accessed only by group members.
- A participant code should replace names in working datasets.
- The public repository should contain only the anonymized cleaned dataset and supporting code.
- Any private group list or consent records must be kept outside the repository.
- Data should be retained or deleted according to university requirements and ethical approval.

## Sensitive or Public Content

The project will not infer private motives from an observable action or publicly accessible post. Participants' context must be represented fairly.

## Approval Status

Complete institutional or instructor ethics review requirements before actual data collection begins.
