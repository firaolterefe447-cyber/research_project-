# Interview and Open-Response Codebook

## Coding Procedure

Code complete relevant segments. Multiple codes are permitted. Preserve context and retain only anonymized quotations.

| Code | Definition | Example criterion |
|---|---|---|
| TIME_LOSS | Instructional or administrative time is lost | “It takes ten minutes” |
| INACCURACY | Records contain errors or omissions | Missing names or incorrect marks |
| FRAUD | Proxy or false marking is reported or possible | Students signing for absent peers |
| WORKLOAD | Staff or instructors have high processing workload | Entering, checking, and correcting records |
| ACCESS | Students have limited devices or internet access | No smartphone or unreliable connection |
| COST | Technology, devices, or maintenance are expensive | Funding or maintenance concerns |
| PRIVACY | Concern about collecting or storing personal data | Identity, location, or use restrictions |
| TRAINING | Users require instruction or technical support | Student or instructor guidance |
| USABILITY | The system is easy or difficult to use | Simple or confusing process |
| BENEFIT_SPEED | Digital system saves time | Faster record entry |
| BENEFIT_ACCURACY | Digital system improves correctness | Fewer manual errors |
| BENEFIT_REPORTING | Records are easier to retrieve or summarize | Automated reports |
| ACCEPTANCE | A participant supports or rejects adoption | Willing to use or unwilling |
| FAIRNESS | The system should accommodate all users | Offline and accessibility options |
| SECURITY | Identity verification or unauthorized access is considered | QR abuse or account misuse |

## Qualitative Interpretation

Record code frequency, representative anonymized excerpts, and theme relationships. Do not treat frequency as importance or causation.
