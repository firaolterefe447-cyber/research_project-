# Data Management

The public repository must contain only cleaned, anonymized, and ethically appropriate data.

## Required Dataset Structure

Use `anonymized_responses.csv` with a participant code and questionnaire variables only. Do not include names or student IDs.

Suggested variables:

- `participant_code`
- `participant_role` (student/instructor)
- `study_level`
- `department_code`
- `class_size_category`
- `attendance_method`
- `manual_time_problem` through `digital_acceptance` using Likert values 1–5
- `open_response_1`, `open_response_2`, `open_response_3`

## Before Uploading

1. Remove direct identifiers.
2. Replace names and institutional identifiers with non-identifying codes.
3. Generalize small or sensitive categories.
4. Search for names, phone numbers, emails, and free-text identifiers.
5. Review the data dictionary.
6. Verify that informed consent and institutional requirements permit public sharing.

## Collection Log

Record only aggregate and operational information: dates, participant count, pilot status, instrument version, and data quality issues.
